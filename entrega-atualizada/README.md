# Entrega - versão MySQL

Esta pasta contém a versão atualizada do Sistema Web de Gerenciamento de Biblioteca.

- `projeto-mysql/`: código-fonte completo da aplicação configurada para MySQL 8.4 e Docker Compose.
- `documentacao/`: guia de instalação, execução e publicação em DOCX e Markdown.
- `Projeto_Biblioteca_MySQL_Atualizado_COM_GUIA.zip`: pacote anterior. Para receber as alterações mais recentes, baixe a branch inteira e use `projeto-mysql/`.

Para começar, abra [`projeto-mysql/`](projeto-mysql/) no VS Code e siga o [roteiro de execução local](projeto-mysql/docs/EXECUCAO_LOCAL.md).

O [guia completo](projeto-mysql/docs/GUIA_COMPLETO_INSTALACAO_EXECUCAO_GITHUB.md) também está disponível. Os testes usam H2 em memória e não exigem MySQL ou Docker.
